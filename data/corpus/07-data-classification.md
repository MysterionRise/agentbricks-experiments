# Data classification

Owner: Security. Applies to all data created or handled at Halcyon Freight.

## The four classes

| Class | Examples | Who may access |
|---|---|---|
| **Public** | Marketing material, published prices, job adverts | Anyone |
| **Internal** | This handbook, org charts, meeting notes, most wiki pages | All employees and contractors |
| **Confidential** | Customer contracts, shipment manifests, financial results before publication, source code | Named teams on a need-to-know basis |
| **Restricted** | Payroll data, personal data of employees and drivers, security findings, credentials | Named individuals; access is logged |

If you are unsure which class applies, treat the data as Confidential and ask the
Security team.

## Handling rules

- **Public**: no restrictions.
- **Internal**: may be shared with anyone who has a Halcyon account. Do not post
  externally.
- **Confidential**: store only in approved systems (Atlas, Beacon, Ledger, the company
  code hosting). Share externally only under a signed non-disclosure agreement. Do not
  print at home. Encrypt when sent by email.
- **Restricted**: store only in the system of record. Never email, never download to a
  laptop, never paste into any external tool, including AI assistants that are not on the
  approved list. Access is reviewed every **quarter** by the data owner.

## Labelling

Documents in Atlas carry a classification label. Documents without a label are treated
as Internal. Confidential and Restricted documents must carry the label in the header
and the file name.

## Retention

- Shipment records: **7 years**.
- Financial records: **10 years**.
- Candidate data for unsuccessful applicants: **6 months**, then deleted.
- Security logs: **13 months**.

## AI tools

Employees may use AI assistants on the approved list with Public and Internal data.
Confidential data may be used only with the internal assistant hosted on the company
data platform. Restricted data may not be used with any AI tool.

## Breaches

Any suspected exposure of Confidential or Restricted data is a security incident. Report
it immediately following the incident response policy. Reporting a mistake you made
yourself is encouraged and is not a disciplinary matter.
