# About this handbook

Halcyon Freight is a fictional mid-size logistics company used as the knowledge corpus
for this repository. Every document in this folder is invented. Nothing here describes a
real company, person, policy, or price.

The corpus exists so that evaluation questions have exact, checkable answers that a
language model cannot already know from pre-training. If an assistant answers a question
about Halcyon correctly, it did so by reading these files, not by recall.

## Structure

| Document | Owner | Covers |
|---|---|---|
| 01-company-overview | People team | Who we are, sites, headcount, org |
| 02-time-off-policy | People team | Annual leave, sick leave, parental leave |
| 03-expense-policy | Finance | What is reimbursable, limits, receipts |
| 04-travel-policy | Finance | Booking, class of travel, per diems |
| 05-remote-work-policy | People team | Eligibility, equipment, time zones |
| 06-hardware-and-devices | IT | Laptops, refresh cycle, lost devices |
| 07-data-classification | Security | Four data classes and handling rules |
| 08-security-incident-response | Security | Severity levels, who to call, timelines |
| 09-on-call-rotation | Engineering | Rotation, paging, compensation |
| 10-deployment-runbook | Engineering | Release windows, approvals, rollback |
| 11-vendor-onboarding | Procurement | Steps and thresholds for new suppliers |
| 12-glossary | All | Internal terms and acronyms |

## Precedence

When two documents disagree, the more specific document wins. For example, the travel
policy's receipt rule for hotels overrides the general expense policy's receipt rule.

## Versioning

This handbook is version 3.2, effective 1 March 2026. Policy owners review their
document every six months. Questions about a policy go to its owner in the table above.
