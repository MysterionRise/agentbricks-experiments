# Glossary

Internal names and terms used across the handbook.

| Term | Meaning |
|---|---|
| **Atlas** | The internal wiki. Home of this handbook, the leave module, the IT service desk and vendor requests. |
| **Beacon** | The customer portal where customers book and track shipments. Owned by the Customer Portal team. |
| **Compass** | The internal routing and dispatch system. Owned by the Routing team. |
| **Ledger** | The finance system, including expenses and vendor records. Owned by Finance. |
| **Waypoint** | The company travel booking tool. |
| **Hub** | A distribution centre. Halcyon has hubs in Duisburg and Lyon. |
| **Core hours** | 10:00 to 15:00 Central European Time, when office-based staff are reachable. |
| **Anchor days** | The two days each team is in the office. Most teams use Tuesday and Thursday. |
| **Peak freeze** | The period from 15 November to 5 January with no routine production deployments. |
| **Canary** | A rollout that sends 5 percent, then 50 percent, then all traffic to a new version. |
| **Primary / Secondary** | The first and second engineer paged on an on-call rotation. |
| **P1, P2, P3** | Alert priorities. P1 and P2 page; P3 creates a ticket. |
| **Severity 1 to 4** | Security incident levels. Severity 1 is the most serious. |
| **Incident commander** | The person running a security incident; by default the Security on-call engineer. |
| **TOIL** | Time off in lieu. Compensation for incident work outside hours, at 1.5 times. |
| **Per diem** | A fixed daily allowance for meals while travelling, replacing individual meal claims. |
| **DPA** | Data processing agreement, required with any vendor handling personal data. |
| **Restricted** | The highest data class: payroll, personal data, credentials, security findings. |
| **Sponsor** | The employee who requests and owns a vendor relationship. |
